# Safa

The modern almanac for mindful living: a daily app that brings the world's calendars,
moon phases, seasons and observances into one calm daily screen.

| Folder | What |
| --- | --- |
| [`app/`](app/) | The Expo / React Native app (iOS, Android, web). Start with [`app/README.md`](app/README.md). |
| [`app/data/`](app/data/) | The master calendar CSV (Jun 2026 – Jun 2027) and the product logic spreadsheet. |
| [`design/`](design/) | The Claude Design handoff the app was built from: prototype, design system and design chat. |

```bash
cd app
npm install
npx expo start   # scan the QR code with Expo Go on the same Wi-Fi
```
